# Sonance EQ over MQTT

[`sonance-powerzone-mqtt`](sonance-powerzone-mqtt/README.md) is a local bridge from authenticated or
LAN-contained MQTT brokers to Sonance PowerZone output EQ. It provides a stable command/state contract
for openHAB, Node-RED, ioBroker, Hubitat community apps, Home Assistant, and other MQTT clients.
