# Screenshot Scout / Creator Library

Screenshot Scout makes a searchable local index of images and videos a person explicitly selects from Photos. It uses Apple's Vision framework on-device to recognize visible text and suggest image labels. Search supports multiple terms in any order across recognized text, scene descriptions, and labels. While a query is debounced or the local index is being searched, the interface shows a pending state instead of a temporary no-results message. It detects byte-identical reimports by SHA-256 before storing another copy, using in-memory digest sets rebuilt from the saved JSON indexes to avoid rescanning every saved record for each selected file. A person can stop a multi-image import after the image currently being analyzed finishes. They can also ask Vision to rank the closest images already in the local index for side-by-side review and cancel the scan; visual similarity is a suggestion, not proof of a duplicate, and the app never removes an image automatically.

For a selected video, the app keeps a private full-resolution copy and samples five frames across its duration. Vision reads visible text and scene labels from those frames. On iOS 27, a person can optionally draft and edit a separate scene description for an individual sampled frame using the on-device image model. The model receives that frame image only; the app does not submit the entire video. Search cards show the timestamps of sampled frames containing query terms, and opening a result gives access to the original video and sampled moments for review before using any clip. Video indexing can be cancelled, and exact duplicate videos are skipped using a streaming SHA-256 pass. The detail screen can share a timestamped text export of sampled OCR, labels, and reviewed descriptions; it does not include the video.

The library exports a JSON inventory without media copies. The user chooses metadata only or an explicit option to include recognized text, Vision labels, and any saved scene descriptions. A persistent review queue lets the user save selected images and videos for later inspection, open each item from the queue, and remove it from the queue after review. Queue entries are included in the JSON inventory; nothing is deleted automatically.

On iOS 27 builds, an optional Foundation Models path can suggest a short visual scene description for one selected image or one sampled video frame at a time. It passes the local image URL to Apple's on-device model only when the system reports the model ready and image support available. The user reviews or edits the suggestion and explicitly saves it to the local search index. If the user edits the draft, saves or clears a description, removes the source item, or closes its detail screen while generation is in flight, the stale result is discarded. The description is a search aid, not verified image or video metadata. This path is compile-gated for the Swift 6.4 compiler in Xcode 27.

Image copies, selected video copies, sampled frames, review queue, and JSON indexes are stored in the app's Documents folder. The app marks the library folder and its media, frame, and index files for device-backup exclusion, reapplying the file hint after atomic index writes and when reopening the library. Apple describes this as backup guidance, not an absolute guarantee. Analysis runs locally. It does not scan the photo library, access other apps, upload media, or delete originals from Photos. Removing an item first saves the updated image, video, and review-queue indexes, restoring the prior in-memory entries if persistence fails; only then does it delete Screenshot Scout's private media copy and sampled frames. If media cleanup fails after the index update, the app reports that the private copy remains. If an image cannot be indexed after import, the private copy is removed and the library index is restored on a best-effort basis.

Build the project with XcodeGen and Xcode:

```sh
xcodegen generate --spec iOS/Utilities/ScreenshotScout/project.yml --project iOS/Utilities/ScreenshotScout
xcodebuild -project iOS/Utilities/ScreenshotScout/ScreenshotScout.xcodeproj -scheme ScreenshotScout -destination 'generic/platform=iOS Simulator' -jobs 1 CODE_SIGNING_ALLOWED=NO build
```

The app's core image and video features target iOS 17 and do not depend on iOS 27 APIs. The optional scene-description feature is compile-gated for iOS 27. The last verified local build used Xcode 26.0.1; Xcode 27.2 is now installed, but its first-use license has not been accepted, so a current-SDK build is pending. Camera/photo runtime behavior has not been exercised. No phone install or release is part of this project. Apple's backup guidance is documented in [Optimizing your app's data for iCloud Backup](https://developer.apple.com/documentation/foundation/optimizing-your-app-s-data-for-icloud-backup) and the [`isExcludedFromBackup` resource value](https://developer.apple.com/documentation/foundation/urlresourcevalues/isexcludedfrombackup).
